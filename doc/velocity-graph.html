VelocityGraph

A tool to show you the velocity of your shooter.

Step 1. Copy the VelocityGraph.java into your teamcode folder:

Step 2. Create a variable at the beginning of your Remote Control program:

private final VelocityGraph velocityGraph = new VelocityGraph();

Step 3. At the start of your remote control opmode, start the Velocity Graph

// after init
velocityGraph.start();

Step 4. Every loop, log the speed, pvalue, and fvalue to the tool

// every loop
velocityGraph.setVelocity(shooter.getVelocity());   // required
velocityGraph.setTarget(shooterSpeed);         // optional: target line
velocityGraph.setPValue(pvalue);               // optional: shows P
velocityGraph.setFValue(fvalue);               // optional: shows F

Step 5. At the end of your remote control OpMode, stop the VelocityGraph

// after the loop
velocityGraph.stop();

Step 6. Put your code on the robot

Step 7. Open the graph

Make sure the laptop remains connected to the robot

Run connect-robot.bat (open it from your Downloads, or double-click it in the doc folder)

Start the remote control OpMode

Open this page: http://localhost:8000

You can start and stop the opmode without refreshing this page.
