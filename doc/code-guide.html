The Files

Remote.java

Our primary program that runs and collects commands from the remote control and sends them to Yoshi.java.

  • runOpMode()Initializes Yoshi, waits for Start, then runs a while loop with the 4 functions.
  • handleIntakeControls()Reads the Triangle/Cross and sends the values to Yoshi.java.
  • handleSpeedControls()Reads D-pad input and sets the maximum wheel speed.
  • handleJoysticks()Reads the joysticks and sends the values to Yoshi.java.
  • sendTelemetry()sends data to the driver station.

Yoshi.java

Describes the hardware that we have on our robot and sends commands to the hardware.

  • init(hardwareMap)Configures the hardware (this must match the configuration in the driver station)
  • drive(axial, lateral, yaw, max)Receives the commands from the joysticks and calculates the power that should be used for each wheel then sets the wheel powers.
  • setWheelPowers(fl, fr, bl, br)Sets the wheel power to the specified values.
  • stopDrive()Sets every wheel power to zero.
  • setIntakePower(power)Sets the intake motor to a requested power.

RobotConstants.java

Stores numbers that we use and change a lot.

  • Hardware namesMust exactly match the names configured on the Driver Station.
  • Wheel presetsDefine the options for wheel speed.
  • Joystick thresholdDefines how much small stick motion should be ignored.
  • Intake valuesDefine the starting power and adjustment size.
